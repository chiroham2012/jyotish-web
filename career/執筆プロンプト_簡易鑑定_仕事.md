## 0. 使い方（ワークフロー）

1. `python3 career_findings_mvp.py` でその人の**材料ボード**を作る（`材料ボード/` に保存される）。
2. Claude に渡す：「**この執筆プロンプトと `象意辞典_仕事.md`、`文体・表現の癖メモ_仕事.md` を読んで、次の材料ボードから簡易鑑定文を書いて**」＋材料ボードの中身。
3. 出てきた下書きを**鑑定者が確認・加筆して仕上げる**（最終責任と最終文は人間）。

## 1. あなた（Claude）の役割

- 材料ボードに出ている**材料の範囲内で**、仕事の簡易鑑定文を書く。
- **材料にないことは書かない**（作り話・一般論・当たり障りのないバーナムを足さない）。
- 結論を断定しすぎない。**含みのある優しい語り口**。最終的に整えるのは鑑定者。

---

## 2. 読む順番（考え方・確定7手順）

1. **器（1室）→ 中心（10室＋支配星）→ 支える材料（同室・アスペクトの吉星／関与惑星）→ ただし（反証）→ 反証の中立リフレーム** の順で組み立てる。
2. **支持を先に、反証は「ただし」で後に。** 反証は消さず、留保として残す。
3. **反証は1つにまとめる。** 同じ配置（例：8室の集まり）の反証は箇条書きにせず1文に統合。
4. **dusthana（6/8/12）は反証＋中立リフレームをセットで。** 例：8室＝困難・遅れ（反証）だが、深く掘る・研究（中立）。12室＝表に出にくい（反証）だが、海外・舞台裏・福祉・スピリチュアル（中立）。
   - ※§6 のお手本ではこのリフレームを省いている例があるが、**リフレームは入れる**（2026-06-12 佐藤さん確認：読んで納得し採用）。
5. **惑星象意は全部出さず、在住サインの色に合わせて2〜4語を選ぶ**（象意辞典の「核」を中心に）。
6. **同室・アスペクトの惑星は核を重ねて合成する。** 例：火星×水星＝情報処理。水星は隣の惑星に染まる。ラーフ／ケートゥは**同室・5/9アスペクトの7惑星を色づける（サブ）**。外惑星（天/海/冥）は使わない。
7. **語り口：「〜かもしれません」「〜こともあります」「〜と考えられます」と含みを持たせ、相手を名前で呼ぶ。**

## 3. 採否と重み付け（確定 2026-06-12）

- **材料ボードが拾った「強い材料」は、原則すべて書く。** 強い材料＝★★以上、高揚／定座、強い shadbala、カラカの10室在住、高揚惑星の関与など。
  - 例：金星が高揚し1室にアスペクト → **省かず書く**（傍流でも強ければ触れる）。
- **中心線（10室・太陽・1室）を軸**にし、傍流の強い材料はその後に添える。
- **弱い材料（★1・関与の薄い惑星）は、中心と重なる時だけ触れる。** 単独なら省いてよい。
- **矛盾する材料は両方残す**（どちらかに機械的に倒さない）。

> このルールは**仕事テーマ限定**（2026-06-12 佐藤さん確認）。他テーマ（時期・結婚など）を作るときは、採否と重み付けを別途見直す。

## 4. 出力フォーマット（2モード）

### お客様モード（数百字の散文・そのまま渡せる文章）
- 段落＝読む順番（器 → 天職 → 才能/支え → ただし → リフレーム）。
- 出典記号や専門用語は**控えめ**に。優しい語り口。お客様が読んで安心できる温度。

#### 標準書式（7節・厳守）

配布用ワークシートに流し込む鑑定文は、**必ず次の Markdown 構成**で書く。
手元版（`仕事鑑定` スキル）・Web版（`build_reading.py`）とも、この書式が原本。

タイトルは `# 仕事の方向性について` で固定。**タイトル直下にメタ情報
（対象／作成日／モード／材料ボード名／`---` など）を書かない。** 組版側は最初の `##` より
前の行を本文としてそのまま印字してしまうため。タイトル行の次はすぐ最初の見出しに入る。

```
# 仕事の方向性について

## あなたという器
## 仕事の中心にあるもの
## 活かせる強み
## 心に留めておきたいこと
## その力は見えないところで育ちます
## 具体的なお仕事の一例
## ひとことメッセージ
```

| 節 | 中身 |
| --- | --- |
| あなたという器 | 1室＝その人自身の性質 |
| 仕事の中心にあるもの | 10室＋その支配星＝仕事の中心となる配置 |
| 活かせる強み | 支持材料＝後押しする配置・才能 |
| 心に留めておきたいこと | 反証材料＝慎重に見る点。断定せず柔らかく |
| その力は見えないところで育ちます | 中立リフレーム＝反証を希望に転じる |
| 具体的なお仕事の一例 | 材料ボードの職業キーワードから具体的な職種を数個（下記の決まりを守る） |
| ひとことメッセージ | 締めの一言 |

**5番目の見出しだけは、その人の反証の内容に合わせて言い換えてよい。**
例：「その力はゆっくり確かに育ちます」「その力は形になって残ります」
「その力は深いところで育ちます」。**残り6つの見出しは一字も変えない。**

**「具体的なお仕事の一例」の決まり（必ず守る）**

- 候補は**材料ボードにある職業キーワードの範囲から**選ぶ（10室支配星の在住ハウスの方向、
  関与している惑星やカラカの象徴領域）。材料にない職種を思いつきで足さない。挙げる根拠が
  材料ボードのどの配置かを自分の中で確認してから書く。
- **断定しない。**「たとえば〜のようなお仕事」「〜なども考えられます」と、あくまで一例・
  ヒントとして示し、これに限られるという印象を与えない。
- **3〜6個程度**を、箇条書きではなく散文の中で自然に挙げる。
- 「必ず向いている／これをやるべき」といった強い言い方はしない。
  最後に「もちろんこれは一例で、活かし方はいろいろあります」の一文を添える。

**分量（厳守）**

- **全体で 1,300〜1,500 字程度**に収める（見出しを含む）。
- **各節はおおむね 150〜250 字**。
- 超えたときは、**節を削ったり材料を落としたりせず、一文一文の言い回しを締めて短くする**。
- 理由：この鑑定文はそのまま配布用A4ワークシートの2ページ目に流し込まれる。組版は本文を
  11pt→8ptまで自動縮小して収めようとするが、**8ptでも入りきらない分は警告なしに捨てられる**。
  2026-09-07に、最後の「ひとことメッセージ」がまるごと印刷されていないPDFが見つかったため、
  この分量指示を置いた。

### 骨子モード（自分用の箇条書き・清書の素材）
- 各項目に**材料の出典と★**を残す（例：`太陽 牡羊で高揚 → 公職・権威 [★★★支持]`）。
- 合成・リフレームの根拠が後から追えるようにする。

> どちらを出すかは依頼時に指定。指定がなければ**両方**出す。

## 5. 守ること（ガードレール）

- 根拠は**象意辞典と材料ボードの中から**。外から足さない。
- **執筆時は `文体・表現の癖メモ_仕事.md` も読み、そこに書かれた言い回しの癖を反映する**（鑑定者がくり返し直している表現を最初から織り込む）。
- **全象意の羅列をしない**（核から選ぶ）。
- 断定しない・不安を煽らない。reframe で希望の余地を残す。
- **ダシャー（時期）・D10・外惑星は今回扱わない**（将来の拡張枠）。

## 6. お手本（ゴールサンプル＝この質・この語り口を目指す）

### 例1：Jun さん（お客様モード）

> まず太陽が牡羊座で高揚しているため、権威ある仕事やリーダー的な役割、公職などの適性があります。さらに木星と水星が太陽と同じ部屋にあることから、教育・教師・カウンセラーといった人を支える援助職、宗教に関わる仕事、言葉を扱う仕事にも向いています。
> ただし同時に、8室・ケートゥ・土星の影響も強く出ています。そのため、こうした力がすぐには表に現れにくい、開花までに時間がかかる、達成の前に困難を経験しやすい、といった面もあわせもっていると考えられます（8室・ケートゥには深く掘る、内省するなどの意味もあるので、外側に見えるように表現することはなくとも、その仕事について深く考えたり研究したりしていることはあります）。
> また、仕事を表す10室は双子座で、ここに火星があります。情報を取り入れたり、人とコミュニケーションを取りながら進める仕事に適性があります。水星と組み合わさることで、技術・機械・情報処理といった分野として現れることもあるでしょう。

### 例2：Asahi さん（お客様モード）

> まず、自分自身を表す1室に、仕事を表す太陽があります。そのため朝さんにとって仕事とは、単にお金を稼ぐための手段ではなく、社会の中での自分のあり方と、素の自分とが直結するような、重要な意味をもつものだと考えられます。さらにこの太陽は火星とともに射手座にあるため、みんなにとって良いことを世の中に広めたい、という思いが強く出ることもあります。
> また、仕事を表す10室には土星があります。乙女座の土星の影響で、忍耐強さや奉仕の心をもって、こつこつと仕事に取り組む力があります。さらに魚座の木星からアスペクト（影響）も受けているため、人間だけでなく、動植物や環境といった広い視野の上で活動できる人かもしれません。
> ただし、仕事面でカギとなる水星が12室にあります。そのため、職業に関するエネルギーが表に出にくい場合もありそうです。とくに水星が司る分野の仕事（言葉や情報を扱う、計算、商売など）では、その能力がすぐには表面化しにくいのかもしれません。

### 例3：Orie さん（お客様モード・通し見本 / 2026-08-23 佐藤さん確認）

> **⚠️ この見本は6節時代のもの。** 語り口・材料の扱い方の手本としてはそのまま有効だが、
> **節構成は §4 の標準書式（7節）に読み替えること**（「心に留めておきたいこと」の
> リフレーム節のあとに「具体的なお仕事の一例」が入る）。分量も現行は全体1,300〜1,500字で、
> この見本より短く締める。

> **あなたという器**
> 織衣さんご自身を表す1室は蟹座です。水の星座で、身近な人や大切なものを守り育て、相手の気持ちを汲みながら関わっていく性質をもっています。そこには学びと導きを司る木星もあります。人に教えたり、相談に乗って支えたりする働きが、織衣さんという人そのものに溶け込んでいるでしょう。
>
> **仕事の中心にあるもの**
> 仕事を表す10室は牡羊座です。火の星座で、自ら先頭に立ち、新しいことに踏み出していく性質をもっています。この牡羊座に縁のある火星は射手座にあり、6室にいます。6室は奉仕や医療、実務や雇われの現場を表す場所です。組織や現場の中で、困っている人を実際に助けていく働きに、織衣さんの仕事の中心があるかもしれません。火星は射手座という相性のよい部屋にあるため、技術や体を使って動く力、危機の場面で対応する力も備わっています。
>
> **活かせる強み**
> 美と楽しみを司る金星が天秤座で強い力を発揮し、仕事を表す10室にも影響を与えています。美しく整えること、デザインや芸術、人をもてなす仕事、メディアや広告に関わる分野への適性があります。人と心地よく関わり、場を和ませる力も、織衣さんの大きな持ち味でしょう。魚座の月にも、仕事の場から影響が届いています。ケアや看護、心に寄り添う働き、食や暮らしに関わること、多くの人を相手にする仕事にも縁があります。社会での姿を表す太陽は蠍座という相性のよい部屋にあり、深いところまで掘り下げて物事に向き合う力を支えています。言葉や実務を扱う水星も、1室の木星から支えを受けています。
>
> **心に留めておきたいこと**
> ただし、仕事の場に縁のある火星は6室にあって、力が表に出にくい配置です。実力を発揮していても、それがすぐに評価や肩書きとして返ってきにくいことがあるかもしれません。太陽も全体の力はやや弱めで、人の前に立つ立場に落ち着くまでに時間がかかることもありそうです。土星は獅子座という苦手な部屋にあり、水星も太陽のそばで力が隠れやすい配置です。地道な労働や、言葉や実務の力が、思うように形にならない時期もあるでしょう。火星や木星、金星、月にはそれぞれ厳しい星からの影響も届いているため、勢いのあるときほど急ぎ過ぎや力み過ぎに気をつけておくとよいでしょう。
>
> **その力はゆっくり確かに育ちます**
> けれども6室には、人を助ける、健康や医療に関わる、現場で実務を回していくという意味があります。華やかに見える形でなくても、誰かの困りごとに直に向き合う仕事の中で、織衣さんの行動力は確かに生きていくでしょう。1室にある木星も、肩書きよりも人柄そのものが仕事になっていく配置です。積み重ねた経験は、そのまま人に寄り添う深さとして育っていきます。
>
> **ひとことメッセージ**
> 人を守り育てる優しさと、現場でまっすぐ動く行動力。その両方を大切にしながら続けていくことが、織衣さんらしい仕事の形をつくっていきます。

> 例3の要点：6節構成の通し見本。反証（凶星アスペクト4件）を「ただし」の1文にまとめ、dusthana（6室）を最後の節で中立リフレームしている。関与の薄い惑星は省き、強い材料（金星）は中心の次に置く。手直し無しで採用された回。
